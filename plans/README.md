# Plans Directory

This directory stores active and archived execution plans used by AI coding assistants.

## Active plans
- Place active plan files in this folder or at repository root using `PLAN*.md`.
- Keep checklist items unchecked until user confirmation.
- While waiting for confirmation, annotate each implemented item with:
  - `Status: implemented, awaiting user confirmation`
  - touched file paths

## Archive
- Move/copy fully confirmed plan sections into `plans/archive/`.
- Use file name format:
  - `ARCHIVED_YYYY_MM_DD_SHORT_TITLE.md`
